- Monitoring already uses native filter controls, optional columns, loaded-record selection and `sheetTableUi`. Existing obligation action menus retain their permission and selected-client policy. No new monitoring sort or bulk endpoint is introduced.
- Fiscal clients/documents retain query owners, XML inspection, exports and explicit mutation boundaries. Processing adopts the shared scroll/heading composition; its plain queue and overview connector queues are now explicit ledger entries. Provider flags and science semantics stay unchanged.
- Admin Account/users/subscriptions already use PanelList. New allowlisted authoritative ordering is wired to the existing adapters, stable IDs and response counts. Global users stay read-only. Plans retain the complete-array local ordering exception. Support and summary views keep fixed ordering.
- Team lists and ordinary business Settings already use the shared panel/card hierarchy. Demonstration notification/security behavior remains demonstration behavior. Native Company settings scalar forms adopt shared row/measure classes while preserving private draft, server errors, conflict resolution and authority invalidation.
- Catalog resource instances share native sorting, optional-column menu, stable IDs, PanelList and the modal editor host. Detail is still a slideover. Units sort by actual_name/short_name; logistics uses its actual carrier/plate fields; CFOP selection remains independent of display sorting.
- Company sales/purchases/stock/finance already use erpOperationalTableUi, derived from the shared panel family. This change deliberately retains content-sized columns, item editors, exact-value display, financial recovery and establishment/warehouse constraints. These are consumer reuse paths, not grounds to invent new controls.
- Reports retain metric layouts and export lifecycle. Accounting delivery keeps its functional table and scoped delivery commands. Accessibility-only tables are not treated as visual table candidates. Company membership/mapping and stock history/detail collections have explicit domain exceptions in the ledger.
- Home, inbox, notification and filter inspectors retain their task-specific containers. Sample handlers are not promoted into product behavior.
