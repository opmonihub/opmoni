# Contact attachment MIME fixtures

`apache-empty.doc` is the Apache POI test-data fixture `test-data/document/empty.doc` from the Apache POI project, copied from the `trunk` source tree. Its SHA-256 is `5f421a3970c70f12296073478380c0849a54c03fb2f4842392c7d3c5039bf1eb`.

The fixture is redistributed under Apache License 2.0. Copies of the current Apache POI trunk license and project notice are included as `LICENSE-Apache-2.0.txt` and `NOTICE-Apache-POI.txt`. Their upstream paths are [`legal/LICENSE`](https://raw.githubusercontent.com/apache/poi/trunk/legal/LICENSE) and [`legal/NOTICE`](https://raw.githubusercontent.com/apache/poi/trunk/legal/NOTICE).

The fixture is used only to verify that the installed server `finfo` recognizes a real legacy Word document as `application/msword`. It is not parsed or executed.
